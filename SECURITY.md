# Security policy

Session Exporter has no server, authentication flow, analytics, or network integration. Its primary security boundary is preventing hidden instructions, credentials, and unrelated private data from entering an export.

Please use the repository's private vulnerability reporting flow for suspected security or privacy issues. Do not include real credentials, private transcripts, or other sensitive data in a public GitHub issue.

Public, non-sensitive bugs can be filed at <https://github.com/Tor-Production/session-exporter/issues>. Private reports can be opened at <https://github.com/Tor-Production/session-exporter/security/advisories/new>.
