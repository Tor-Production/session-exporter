Git marketplace

Install in Codex

codex plugin marketplace add Tor-Production/session-exporter --ref main
codex plugin add session-exporter@tor-production

Start a new task after installation, then invoke $session-exporter or ask to export the complete current session.

The universal Plugins Directory listing is subject to OpenAI review and approval. The Git marketplace package is independently installable from this public repository.

The artifact

One file, with evidence

The default session_export.md includes metadata, a compact executive summary, current state, decisions, Git and deployment state, important files and commands, the complete accessible transcript, a material-action timeline, open questions, handoff instructions, and an integrity report.

Hidden system instructions and private chain-of-thought are never exported. Known omissions and redactions are disclosed.
