Visual Codex

Install without a terminal

Open in Plugins Directory
  1. Open the public listing above while signed in to the ChatGPT account you use with Codex.
  2. In the ChatGPT desktop app, open Plugins, find Session Exporter by Tor Production, open its details, and select the + button.
  3. Start a new Codex task so the newly installed skill is available.
  4. Ask to export the complete current session, or invoke $session-exporter explicitly.

The button opens the public directory entry. Select + there to complete installation.

Command-line alternative

codex plugin marketplace add Tor-Production/session-exporter --ref main
codex plugin add session-exporter@tor-production
Regular Chat fallback

Use the public instructions without installing

If a normal Chat (not Work) does not expose the skill, it can still follow the public skill source. This does not install the plugin or expand what the Chat can access.

Read this public skill:
https://github.com/Tor-Production/session-exporter/blob/main/plugins/session-exporter/skills/session-exporter/SKILL.md

Follow its instructions as if it were installed. Export the accessible current conversation as a structured Markdown handoff. Select only sections supported by the real context; omit inapplicable or empty fields. Do not ask me to choose a language. Do not invent inaccessible history, hidden instructions, or metadata. Redact secrets. Return the completed Markdown here, or attach a .md file if this chat supports files.

If the Chat cannot open external links, paste the contents of SKILL.md into the conversation with the same request.

The artifact

One file, with evidence

By default, each export gets a short context prefix and local timestamp, such as plugin-publish-review__20260916-1430__session_export.md, so files from different sessions are easy to distinguish. It always includes compact session context, an executive summary, the complete accessible transcript, and an integrity report. Current state, decisions, Git or deployment state, important files, commands, timelines, and handoff notes appear only when they are genuinely useful.

Hidden system instructions and private chain-of-thought are never exported. Known omissions and redactions are disclosed; irrelevant fields are omitted rather than filled with placeholder values.
