Help

Support

For bugs, installation problems, or feature requests, open a GitHub issue. Include the plugin version, host product, operating system, exact request, actual result, and expected result.

Before filing an issue

  • Start a new task after installing or updating the plugin.
  • Confirm that Session Exporter is installed and enabled in the Plugins Directory, or that session-exporter@tor-production is installed when using the Git marketplace.
  • Check whether the export contains an integrity report explaining inaccessible history.
  • Remove private transcripts, credentials, tokens, and proprietary source before posting logs.

Installation and regular Chat

For the graphical Codex experience, open the public Plugins Directory listing, select +, and start a new Codex task. If a regular Chat does not expose the skill, use the public-instructions fallback on the home page instead.

Security and privacy reports

Do not file sensitive details publicly. Use private vulnerability reporting with a minimal reproduction and no real credentials or private transcript content.

Scope

Support covers the open-source skill instructions and package metadata. Access to old messages, file creation, and available tools depends on the host product and environment. Tor Production cannot recover content that the host does not expose to the active agent.
