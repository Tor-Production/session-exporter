Privacy Policy

Effective: September 14, 2026

Session Exporter is a skills-only plugin published by Tor Production. It provides instructions that help ChatGPT or Codex create a Markdown export in the user's current environment. The plugin has no server, user account, authentication flow, analytics, advertising, or telemetry.

Data processed

At the user's request, the host product may process content already accessible in the current conversation, including user and assistant messages, visible tool or terminal output, commands, URLs, decisions, errors, project metadata, and repository state. This content can contain personal, confidential, or proprietary information supplied by the user or present in their workspace.

Purpose

The data is used only to create the export the user requested for continuity, audit, archival, or workflow analysis. Session Exporter instructs the host to omit hidden system instructions and private chain-of-thought, redact secret values, and mark unavailable content rather than inventing it.

Recipients and transfers

Tor Production does not receive the conversation or generated export. The plugin does not upload, email, publish, synchronize, or otherwise transmit the artifact. The host product and environment may process data under their own terms and privacy notices. A user can separately choose to send or store the export elsewhere; that destination's terms then apply.

Retention

Tor Production retains no user conversation data because the plugin has no collection endpoint. A generated file remains wherever the user or host environment saves it until the user or workspace administrator deletes it. Retention by ChatGPT, Codex, GitHub, a filesystem provider, or another destination is controlled by that provider and the user's configuration.

User controls

  • Invoke the plugin only when an export is wanted.
  • Choose a narrower scope, filename, or output location.
  • Review, edit, move, or delete the generated file.
  • Request redaction or omit sensitive sections before sharing.
  • Disable or uninstall the plugin at any time.

Security

The plugin is designed to avoid secret values and hidden product instructions. No automated redaction is perfect; users should review an export before sharing it outside the original environment.

Children

Session Exporter is a general productivity workflow and is not directed to children. It does not knowingly collect personal data from any person.

Changes

Material changes will be published in this repository and reflected by a new effective date. Version history is available through Git.

Contact

Privacy questions can be filed through GitHub Issues without attaching private transcripts or credentials. Sensitive reports should use the repository's private vulnerability reporting flow.
