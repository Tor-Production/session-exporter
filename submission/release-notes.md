# Release notes for OpenAI review

Initial submission of Session Exporter 0.1.0 by Tor Production.

Session Exporter is a skills-only productivity plugin that creates a structured Markdown handoff of the complete accessible current conversation and relevant workspace state. It preserves chronological user and agent messages, visible operational history, decisions, commands, errors, and verification evidence; marks inaccessible content; redacts secret values; and finishes with an integrity report.

The plugin has no MCP server, authentication, external API, UI, analytics, or telemetry. It does not upload or transmit generated exports. Reviewers need no test account or fixture data and can run all supplied cases in a disposable conversation.

This is the initial public submission. No prior version has been published in the universal Plugins Directory.
